# Nuralqalb9

A web app presenting **Asma ul Husna — the 99 Names of Allah** with their Arabic script, transliteration, meaning, in-depth explanation, Qur'anic reference, and a short reflection for each name.

Built with a Flask backend and a vanilla JS frontend styled in a cream, minimal aesthetic.

## Features

- All 99 names with Arabic calligraphy, transliteration, and short meaning shown in a browsable grid
- Click any name to open its full detail, extended meaning, Qur'anic reference, and a reflection, fetched live from the backend
- Server-side search across name, meaning, and Arabic text
- Random name button for daily reflection
- Light / dark theme toggle
- Fully responsive layout
- Previous / Next navigation inside the detail view, with keyboard arrow support

## Tech stack

- Backend: Python, Flask
- Frontend: HTML, CSS, vanilla JavaScript (Fetch API)
- Fonts: Amiri (Arabic), Cormorant Garamond, Inter
